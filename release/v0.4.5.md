# Kinmokusei v0.4.5

This patch release adds application redistribution notices to `keika build`
and strengthens exception-flow and Task-ownership checks.

## Application license materials

- `keika build -o app` produces the executable and `app.licenses/`. Keep the
  entire directory with the executable when redistributing an application.
- Collect Go's original license and patent grant from the actual build toolchain,
  target-selected nested licenses/notices and complete additional-attribution
  source supplements, including cgo source/header files.
- Include detected notices for imported Go modules, replacements, the locked
  external Kinmokusei source-package graph and generated runtime helpers.
- Record toolchain, target, build tags, dependency identities and SHA-256 hashes
  for notices and the executable, without local checkout paths.
- Missing dependency license text, empty/unsafe notice files and opaque binary
  objects stop the build. Failed builds preserve old outputs; manually added or
  modified notices are not silently deleted during rebuilding.
- Normal builds stay offline and do not update manifests or locks.

The inventory is not legal-compliance certification. Review actual license terms,
source-offer/modification obligations and separately linked native/system libraries.
Manifest SPDX metadata is not a substitute for license text. `run`, `emit-go` and
direct `go build` do not produce the application notice directory.

## Correctness

- Preserve Task ownership through `finally` before explicit returns and Result
  propagation complete, including await/detach in cleanup paths.
- Check intermediate exception paths in `try`, `catch` and `finally`, preventing
  nullable reads after interrupted execution while accepting valid restorations.
- Track ordered value-switch case evaluation, grouped first matches and
  fallthrough without repeating case-expression effects.

## Compatibility

Use matching v0.4.5 compiler and editor releases. The patch preserves the released
string semantics; verified UTF-8 `string`/`bstring` changes are not included.
Stronger diagnostics can reject invalid nullable/Task programs, and application
builds now require dependency license text rather than silently omitting it.

CLI archives are available for Linux/macOS (amd64/arm64) and Windows (amd64),
with the matching VS Code extension and `SHA256SUMS`.

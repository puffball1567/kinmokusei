# Kinmokusei v0.4.13

Write regular expressions and pattern matches directly in Kinmokusei.
This release also adds TS-style value switches, named results, and richer
struct and generic interoperability with Go. Use matching v0.4.13 compiler
and VS Code extension artifacts.

## Regular expressions and pattern matching

- A `re"..."` literal produces a `Regex`. The compiler validates the RE2
  pattern and compiles each distinct literal once. Use `.test()`,
  `.captures()`, and `.replaceAll()` with verified UTF-8 text.
- A `match` evaluates its subject once and takes the first arm whose pattern
  and optional guard succeed. Match literals, regular expressions, fields,
  sequences, and nullable values. Bindings are local to the arm, and missing
  cases are diagnosed at compile time.
- The language server resolves match bindings and record fields, supports
  rename, and provides completion and hover for `Regex` methods.

```ts
const parts = re"^item-(\d+)$".captures("item-42")
const id = match (parts) {
  case [_, const code] => code
  default => ""
}
```

## Value switches and named results

- In a TS-style switch, `case ...:` and `default:` continue into the next
  body at the end of a case. Use `break` to exit. Go-style `case ... { ... }`
  exits at the end of a case and supports explicit `fallthrough`.
- Functions, methods, and block arrows can declare named result slots with
  valid zero values. A bare `return` returns their current values, including
  updates made by deferred calls.

## Structs, interfaces, and generics

- Embed native structs, imported Go structs, their pointers, native distinct
  value types, and named Go interfaces. Visible fields and methods promote
  through embeddings, including generic instances and aliases.
- Pass native struct values and pointers to Go runtime interfaces and Go generic
  functions with interface or method constraints. Preserve concrete return types
  and Go method-set rules.
- Use explicit-receiver class method expressions such as `Box<int>.read`.
  Inherited, virtual, and abstract methods dispatch through the given receiver.
- Compose named and anonymous source method interfaces with type sets,
  `comparable`, and compatible Go interfaces. Embed Go and anonymous method
  interfaces and extend anonymous bases from named interfaces.
- Use source struct terms in constraints and call type parameters whose
  constraint provides one callable signature. Infer dependent type arguments
  and contextual arrow parameter types from callback bounds. Constraint
  intersections distinguish disjoint function and record shapes.
- Supply slice length and capacity from one call that returns two integers.
  The producer runs once and the checks for sizes and zero values still apply.

## Installation

Update supported Linux and macOS installations with this command.

```sh
keika update --version v0.4.13
```

The release archives cover Linux, macOS, and Windows. Install the matching
VSIX separately. Verify the selected archive against `SHA256SUMS`.
Libraries requiring the new features can declare `min-kinmokusei = "0.4.13"`.

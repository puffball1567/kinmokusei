# Kinmokusei v0.4.8

This patch fixes safe generic text unions at Go interface boundaries and
releases the compiler self-update command alongside additional compiler/CLI
corrections. Use matching v0.4.8 compiler and Visual Studio Code artifacts.

## Safe generic scalar unions (#127)

Constrained wrappers such as this now compile:

```ts
import go reflect from "reflect";

constraint Scalar = ~int | ~string | ~boolean;
function same<T extends Scalar>(left: T, right: T): boolean {
  return reflect.DeepEqual(left, right);
}
```

Each normalized source constraint term is checked independently. Verified
scalar text, named text and safe by-value copies can cross the boundary;
unconstrained parameters and mutable verified-text storage remain rejected.
The correction is covered by semantic safety tests and an independent
handwritten-Go runtime comparison, including linked source modules.

## Compiler self-update

```sh
keika update --check
keika update
keika update --version v0.4.8
```

The default is the latest official stable GitHub release. Linux/macOS installs
verify HTTPS downloads, SHA-256 checksums, archive paths, bundled notices and
the candidate compiler version before atomically switching the launcher.
Failures leave the existing compiler in place. Existing versioned symlink
layouts and older compilers are preserved; other layouts use a sibling
`keika-releases/<version>/` directory. Existing targets and concurrent updates
are rejected rather than overwritten.

Windows supports `--check` and manual-download guidance, not automatic
replacement yet. The command never elevates privileges and does not update
Go, editor extensions, project manifests or locks. Checksums detect corruption;
they are not an independent publisher signature.

## Other fixes

- Preserve source order for structural object field calls and channel receives,
  including nested/contextually typed literals, while retaining canonical
  structural identity and JSON field names (#115).
- Diagnose bindings in the `__kinmokusei` runtime namespace and local
  constructor-factory shadowing before Go emission (#113).
- Parse `keika deps list` help and flags before resolving the optional project
  directory; retain read-only behavior and support `--` (#93).

## Upgrading from v0.4.7

Install v0.4.8 using a release archive or:

```sh
go install github.com/puffball1567/kinmokusei/cmd/keika@v0.4.8
```

v0.4.7 does not contain `keika update`; v0.4.8 is the first release that can
perform subsequent self-updates. Install the matching VSIX separately.
Recheck code using reserved compiler-runtime bindings or constructor-factory
shadowing, which now receives an early diagnostic. Libraries relying on the
scalar-union correction should declare `min-kinmokusei = "0.4.8"`.

The verified UTF-8 `string` / raw `bstring` contract and current null-safety
boundaries are unchanged. This release does not claim complete Go coverage.

CLI archives are available for Linux/macOS (amd64/arm64) and Windows (amd64),
with the matching VSIX and `SHA256SUMS`. Preserve bundled license and
attribution files when redistributing binaries.

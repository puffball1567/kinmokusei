# Kinmokusei v0.4.2

This patch adds missing third-party attribution materials to CLI distributions
and improves generic Go compatibility. Kinmokusei's own license remains Apache-2.0.

## Distribution notices

- Every CLI archive includes `THIRD_PARTY_NOTICES.md` and `licenses/go/`, covering
  the Go runtime/standard library and additional notices in its dependencies.
- Materials come from the actual build toolchain and target. The release gate
  compares their contents after unpacking every platform archive.
- Keep these materials alongside redistributed CLI binaries. Applications built
  with Kinmokusei need their own dependency/license review.

## Language and editor improvements

- Channel-constrained generics support send, receive, checked receives, `select`
  and closing, including imported constraints and generic class methods.
- Constraint intersections can eliminate provably disjoint collection shapes,
  array lengths, channel directions and nominal types, retaining source nullability.
- Eligible `len`/`cap` on nullable fixed-array pointers are constants; explicit
  slice/array declaration types are preserved, including nullable initialization.
- Class upcasts in select sends are retained. Destructured locals show their
  inferred types in editor hover and completion.

Go 1.23–1.27 remain supported. The Go compiler itself is an external prerequisite,
not bundled in these archives. Unresolved type-dependent intersections and
incompatible channel element/nullability contracts remain compile-time errors.

# Kinmokusei v0.4.9

This patch adds safe generic deep comparison at the Go boundary and fixes null
preservation for nullable class-to-interface conversions. Use matching v0.4.9
compiler and Visual Studio Code extension artifacts.

## Safe read-only Go comparison (#131)

```ts
import go reflect from "reflect";

function same<T>(left: T, right: T): boolean {
  return reflect.DeepEqual(left, right);
}
```

Unconstrained native generics, verified `string[]`, nested records/containers
and nullable class values can now be compared without unsafe permission or a
finite scalar union. The compiler verifies the resolved package function and
its exact signature against an audited borrowed-input contract: no writes,
retention after return, input method/callback invocation or returned mutation
capability. Namespace/named import aliases and multiple-result arguments work,
including Task/defer calls. No runtime adapter or data-copy wrapper is added.

The permission is limited to direct calls. Unknown function values and
same-named source functions/methods do not inherit it. Keep the direct Go call
inside a source wrapper. `reflect.ValueOf`, JSON, formatting and interface
assertions retain their ordinary restrictions, including inside comparison
arguments. This does not resolve unrelated framework JSON/reflective-storage
compatibility issues.

Runtime comparison is checked against independent handwritten Go for cycles,
nils, nil versus empty slices, functions, NaN, nested records/maps, generic
imports, Task/defer and single evaluation. Go comparison semantics are retained.

## Nullable class-to-interface conversion (#116)

Assigning a null `User | null` to a compatible `Speaker | null` now produces a
nil interface. It no longer creates a typed nil interface that passes a
`!== null` guard and then crashes on member access.

The correction covers parameters, returns, Result success values, fields,
properties, collections and multiple assignment, including generic owners,
linked aliases, anonymous interfaces and Exception subclasses assigned to
`error | null`. The source is evaluated once, and non-null reference identity
and dispatch are preserved. Raw Go interfaces already containing typed nil
retain ordinary Go behavior. The broader null/zero-value audit remains open.

## Updating

From v0.4.8 on supported Linux/macOS installations:

```sh
keika update --check
keika update --version v0.4.9
keika version
```

Windows users and installations needing a manual update can use the release
archive or `go install github.com/puffball1567/kinmokusei/cmd/keika@v0.4.9`.
Install the matching VSIX separately. Source libraries relying on these changes
should declare `min-kinmokusei = "0.4.9"`.

Archives are provided for Linux/macOS (amd64/arm64) and Windows (amd64), alongside
the VSIX and `SHA256SUMS`. Preserve bundled license/attribution materials when
redistributing the compiler.
